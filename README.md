# 🎂 Aesthetic Birthday Surprise Website

A cute, interactive, and mobile-responsive birthday surprise website built with pure **HTML, CSS, and Vanilla JavaScript**. Designed to replace boring birthday paragraphs with a memorable, personalized experience! ✨

---

## ✨ Features

- 🔐 **Passcode Protection:** Only the birthday person can unlock the surprise using the secret date (`27-09`).
- 🌸 **Interactive Scratch Cards:** Reveal hidden birthday wishes on tap with confetti animations.
- 💌 **Wax Seal Heart Letter:** Tap to open a personalized handwritten-style letter celebrating 10+ years of friendship (Since 2016).
- 📸 **Polaroid Memory Wall:** Elegant photo frames to showcase aesthetic moments and memories.
- ☁️ **Wish Clouds:** Interactive pop-up clouds to choose wishes for the upcoming year.
- 🎵 **Background Music & Confetti:** Ambient music and celebration particle effects.

---

## 🛠️ Built With

- **HTML5** — Semantic layout & structure
- **CSS3** — Pastel aesthetic animations, glassmorphism & responsive mobile layout
- **JavaScript (ES6)** — Interactive screen switching, sound controls & scratch triggers
- **Canvas-Confetti** — Celebration particle effects

## 📸 How to Customize & Add Your Photos

> **Privacy Note:** Personal photos have been excluded from this public repository. The project will automatically load cute aesthetic placeholder images by default!

If you want to use your own photos for your bestie:
1. Download or clone this project.
2. In `index.html`, look for the `<!-- Step 4: Core Memories -->` section.
3. Replace the `src` attribute of the `<img>` tags with your own image paths or image URLs:
   ```html
   <img src="your-photo-1.jpg" alt="Memory 1" />
   <img src="your-photo-2.jpg" alt="Memory 2" />
   <img src="your-photo-3.jpg" alt="Memory 3" />
